# ClipSync 赞助页

这是一个独立静态页面，和桌面应用分开：

- 页面：`docs/sponsor/index.html`
- 收款码：`docs/sponsor/assets/alipay-qr.png`、`docs/sponsor/assets/wechat-qr.png`
- 地址：`https://kai3316.github.io/clipsync/sponsor/`
- 应用右上角的「赞助」按钮点击后用系统浏览器打开这个地址。

## 收款方式

页面只展示两种方式：

- 支付宝
- 微信支付

二维码是用原始收款码解码后重新生成的干净二维码：不再包含中间头像、收款人姓名或其他文字，只保留二维码本身和必要的白边。重新生成也保证了去掉头像后仍然可以正常扫描。

页面不包含 GitHub Sponsors、加密钱包或任何其他收款方式。

## 说明

页面上的文字明确写明：赞助完全自愿，不构成购买软件、服务或公益捐赠，不提供退款和捐赠票据。修改文案时保留这些说明。
