第一次使用

三步就能开始

  • 在两台设备上装好 ClipSync。Windows、macOS、Linux 都可以，互相之间也能传。
  • 连同一个 Wi-Fi，配对一次。两边会显示同一个 8 位数字，核对后确认；以后会自动连接。
  • 照常复制粘贴。在一台复制，另一台直接粘贴；文件拖进窗口就能发送。

隐私

你的内容，优先留在你的设备之间

同一 Wi-Fi 下，电脑之间会直接找到对方；不在同一个网络时，内容会先加密再中转。 两种方式都不需要把内容交给一个云端账号。

  • 第一次配对要核对数字。两台设备会显示同一个 8 位数字，确认一致后才建立信任；以后设备身份变化会提醒你。
  • 跨网络时先加密。在公司和家里之间使用时，内容加密后才离开设备，中转服务只负责转发。
  • 敏感内容可以自动遮盖。信用卡号、身份证号、手机号、密码等可以在发送前替换为 [FILTERED]，在设置里选择要遮盖的类型。
  • 历史和设置都归你管。保留多少、什么时候清理、是否加密保存，都可以在设置里调整。

手机

手机扫一下，就能接着用

电脑上会出现一个二维码。手机相机或浏览器扫一下，就能打开同一份剪贴板历史。 在 iOS / Android 上「添加到主屏幕」后，它就像一个小应用一样随手可用。

  • 查看电脑的剪贴板历史，把内容复制到手机上，或把某一条发回电脑
  • 上传手机里的文件到电脑，也可以下载电脑上的文件
  • 和电脑聊天，查看传输记录
  • 访问码可以随时在电脑上更换或关闭

问答

你可能还想问

两台电脑必须连同一个 Wi-Fi 吗？

不一定。在同一个 Wi-Fi 下最省事，会自动发现对方；不在同一个网络时，打开「互联网同步」也能继续用。

需要注册账号吗？

不用。安装后按屏幕提示连接设备即可，没有账号、没有登录步骤。

复制的内容会被上传到云端吗？

在同一个 Wi-Fi 下，内容直接在你的设备之间传输。跨网络时会先加密再中转；中转服务只负责转发，不保存内容。

手机需要安装 App 吗？

不用。电脑上显示二维码，手机浏览器扫一下就能打开；也可以「添加到主屏幕」，以后像小应用一样使用。

Windows 和 Mac 之间可以互传吗？

可以。Windows、macOS、Linux 之间都能互相连接、同步剪贴板和发送文件。

关闭窗口后，ClipSync 还会在后台运行吗？

会。关闭窗口只是把它收进托盘，剪贴板同步仍然继续。要真正退出，请使用托盘菜单里的「退出」。

下载后还需要安装别的东西吗？

不需要。下载对应系统的安装包，安装后打开就能用。

历史记录太多怎么办？

可以在设置里限制保留数量、查看占用空间，也可以清空全部历史。收藏的内容不会被清空。

macOS 说应用无法验证，怎么办？

在 Finder 里右键点击 ClipSync，选择「打开」，再确认一次。如果仍提示已损坏，可在终端执行：xattr -dr com.apple.quarantine /Applications/ClipSync.app，然后重新打开。
