为什么

不是所有剪贴板工具都一样

大多数方案要么经过云端，要么只认纯文本。ClipSync 走的是另一条路。

能力 ClipSync 云端剪贴板工具

界面

一个窗口装下全部

八个页面，侧栏直达。窗口内用 Ctrl / Cmd + 1–8 切换。 点关闭只是把窗口收起来 —— 程序仍在托盘里跑，要退出请用托盘菜单里的「退出 ClipSync」。

新

另一台设备上的文件，点一下就能拿

A 设备复制了一个文件，B 设备的历史里会出现这一条 —— 文件名和大小，按钮是 下载 而不是 复制。在你点它之前，任何字节都不会移动。

  • 只带文件名和大小。请求里没有路径 —— 路径只在命名它的那台机器上有意义，由那台机器自己决定这次能取到哪些文件。
  • 走已配对的加密链路。收到的文件和普通接收文件落在同一个目录；文件夹会打包成一个 zip。
  • 不写剪贴板。本机并不拥有这个文件，谎称"已复制"没有意义。
  • 失败会说明原因。文件已被移动或删除 / 不是文件 / 已不在那台设备上 / 发送失败 —— 用你当前的界面语言讲出来。

安全

默认就是加密的，不是选项

每台设备首次启动时生成一对 Ed25519 密钥，公钥即身份。数据在线缆上加密两次， 在磁盘上也加密一次。

  • TLS 1.3 承担传输层安全，每个帧体再独立做一次 AES-256-GCM。
  • TOFU 配对：首次信任后锁定对方证书指纹，之后指纹变化立即告警。
  • 落盘加密：私钥与剪贴板历史都是密文，密钥由设备种子经 PBKDF2 60 万次迭代派生，可再加一层预共享密码。
  • 敏感内容过滤：信用卡号、身份证 / 社保号、API 密钥、私钥、密码发送前替换为 [FILTERED]。
  • 中继看不到明文：跨网络时密钥由两端各自派生，中继只见密文，且只在无法直连时启用。

手机

手机扫码即用，不用装 App

电脑上生成二维码，手机浏览器扫一下就是完整界面 —— 在 iOS / Android 上"添加到主屏幕"后，它会成为一个独立应用，有自己的图标和离线外壳。

  • 查看电脑的剪贴板历史，把文字推送过去，收藏，直接复制的手机上
  • 上传文件到电脑，下载电脑上的文件
  • 和电脑聊天，查看传输列表
  • 令牌认证，可随时更换或清除

下载

装上就能用，不需要 Python

安装包自带运行时。macOS 因未公证（需要付费的 Apple 开发者账号）只做了 ad-hoc 签名， 首次打开若提示"已损坏"，执行一次 xattr -dr com.apple.quarantine /Applications/ClipSync.app。

Windows 10 / 11

ClipSync_<版本>_x64-setup.exe 下载安装包 x64，安装后从开始菜单启动

macOS 12+

ClipSync_<版本>_aarch64.dmg 下载安装包 仅 Apple Silicon，不支持 Intel Mac

Linux x86_64

ClipSync_<版本>_amd64.deb ClipSync_<版本>_amd64.AppImage 下载安装包 CI 构建；主要验证在 Windows 与 macOS

桌面版会自己更新：检测到新版本后直接下载、安装并重启。Linux 的 .deb 安装会弹出一次系统密码框，.AppImage 不需要。

旧版界面仍同步发布（clipsync-windows.zip / clipsync-macos-arm64.zip / clipsync-linux*.tar.gz），配置文件与配对记录与新版通用。 源码构建见 README。
