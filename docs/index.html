桌面端 · Windows / macOS / Linux

一台设备复制，另一台即刻粘贴。

装在两台或多台电脑上，同一个 Wi-Fi 下它们会自动找到对方。 复制的内容、文件和聊天直接在这些电脑之间传输，不用注册账号，也不必先上传到网上。 两台电脑不在同一个网络时，打开「互联网同步」就能继续用。

开始使用

三步开始

  • 下载安装。在两台（或多台）需要互相同步的电脑上装好 ClipSync。
  • 连同一个 Wi-Fi，配对一次。两边会显示同一个 8 位数字，核对后确认；之后它们会自动连接。
  • 照常复制粘贴。在一台复制，另一台直接粘贴；文件拖到窗口里就能发送。

安全

内容是怎么保护的

两台电脑在同一个网络时，内容直接在它们之间传输，不经过别的地方。 不在同一个网络时，内容会先加密，再交给公共服务转发；服务看不到内容。

  • 配对时核对数字。第一次连接时双方显示同一个 8 位数字，核对一致再确认；以后对方的设备身份发生变化会收到提醒。
  • 传输和保存都加密。传输前内容会加密；保存在电脑上的剪贴板历史和密钥也是加密的。
  • 敏感内容自动遮盖。信用卡号、身份证号、API 密钥、私钥和密码发送前会替换为 [FILTERED]，可以按需关闭。
  • 转发服务看不到内容。跨网络时，内容先加密再交给转发服务；只在无法直连时才会用到它。

手机

手机扫码即用，不用装 App

电脑上生成二维码，手机浏览器扫一下就是完整界面 —— 在 iOS / Android 上"添加到主屏幕"后，它会成为一个独立应用，有自己的图标和离线外壳。

  • 查看电脑的剪贴板历史，把文字推送过去，收藏，直接复制的手机上
  • 上传文件到电脑，下载电脑上的文件
  • 和电脑聊天，查看传输列表
  • 打开需要访问令牌，可以随时更换或清除

下载

下载安装

安装包自带运行环境，不需要另外安装 Python。macOS 第一次打开如果提示「已损坏」，执行一次 xattr -dr com.apple.quarantine /Applications/ClipSync.app。

Windows 10 / 11

ClipSync_<版本>_x64-setup.exe 下载安装包 x64，安装后从开始菜单启动

macOS 12+

ClipSync_<版本>_aarch64.dmg 下载安装包 仅 Apple Silicon，不支持 Intel Mac

Linux x86_64

ClipSync_<版本>_amd64.deb ClipSync_<版本>_amd64.AppImage 下载安装包 CI 构建；主要验证在 Windows 与 macOS

桌面版会自己更新：检测到新版本后下载、安装并重新启动。Linux 的 .deb 安装会弹出一次系统密码框，.AppImage 不需要。同一局域网里有另一台电脑已经升级时，也可以直接从它那里更新。
