Copy on one device. Paste on another.

Install it on two or more computers, and the ones on the same Wi-Fi find each other. Clipboard content, files and chats travel directly between them, with no account to sign in to and nothing uploaded first. If the computers are on different networks, turn on internet sync and it keeps working.

Getting started

Three steps

  • Download and install. Put ClipSync on the two (or more) computers that should sync with each other.
  • Join the same Wi-Fi and pair once. Both devices show the same 8-digit number; check it and confirm. After that they connect on their own.
  • Copy and paste as usual. Copy on one, paste on the other; drop files on the window to send them.

When to use it

Where it fits

Keep working the way you already do: copy and paste.

Situation How it works
Moving things between a desktop and a laptop They find each other on the same Wi-Fi; pair once, then copy as usual
Home and office computers Turn on internet sync; content is encrypted before a public forwarding service passes it on
Handing a file to the other machine Drop it on the window and pick a device; devices on the same network do not need pairing first
Getting something from the computer on a phone Show the QR code on the computer and open it in the phone's browser, with no app to install

The window

Eight pages

Move between them from the sidebar, or with Ctrl / Cmd + 1–8. Closing the window only puts it away; the app keeps running in the tray, and "Quit ClipSync" in the tray menu is what actually exits.

Security

How your content is protected

When the computers are on the same network, content travels directly between them, with nothing in between. When they are not, content is encrypted first and then passed on by a public forwarding service, which cannot read it.

  • Check the numbers when pairing. The first time two computers connect, both show the same 8-digit number; confirm it matches. Any later change to the other device's identity raises an alert.
  • Encrypted in transit and when saved. Content is encrypted before it is sent; the clipboard history and key stored on the computer are encrypted too.
  • Sensitive content is covered. Card numbers, national ID numbers, API keys, private keys and passwords become [FILTERED] before sending; this can be turned off.
  • The forwarding service cannot read it. Across networks, content is encrypted before it is handed over, and only when a direct connection is not possible.

Phone

Scan a code, no app to install

The desktop shows a QR code; the phone's browser scans it and has the whole interface. Added to the home screen on iOS or Android it becomes an app of its own, with its own icon and an offline shell.

  • Read the computer's clipboard history, push text to it, add favourites, copy to the phone
  • Upload files to the computer and download files from it
  • Chat with the computer and watch the transfer list
  • Opens with an access token, which you can change or clear at any time

Download

Download and install

The installer includes the runtime, so Python is not required. If macOS says the app is damaged on first launch, run xattr -dr com.apple.quarantine /Applications/ClipSync.app once.

Windows 10 / 11

ClipSync_<version>_x64-setup.exe Download x64; starts from the Start menu once installed

macOS 12+

ClipSync_<version>_aarch64.dmg Download Apple Silicon only; Intel Macs are not supported

Linux x86_64

ClipSync_<version>_amd64.deb ClipSync_<version>_amd64.AppImage Download Built in CI; primary testing is on Windows and macOS

The desktop app updates itself: it downloads the new version, installs it and restarts. A Linux .deb install asks for your password once; an .AppImage does not. If another computer on the same Wi-Fi has already updated, the app can update from it too.

Building from source is covered in the README.
