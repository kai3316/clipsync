# 方向与优先级

> 记录于 2026-08-23。指导后续开发取舍。

## 使用场景(威胁模型)

ClipSync 主要部署在**可信局域网**环境:家庭、办公室、熟悉的网络、自己的路由器。
**不是**面向敌意公网 / 不可信网络的产品。

## 优化优先级

**功能新增 + 稳定性 > 安全加固。**

- **主要投入**:功能增加、稳定性(崩溃 / 竞态 / 边界)、跨平台一致性。
- **安全设计缺陷**(配对码 MITM、私钥混淆、帧加密冗余、TLS 证书未绑定等)按**低优先级**处理:
  - 只修低成本 / 诚实性项:docstring 过度宣称、UI「加密已启用」误导标签、TLS 证书绑定。
  - **不做**重量级配对协议重设计(commit-then-reveal 等)——有 UX 代价,对可信局域网收益低。
